## [2026-08-13] eval-harness-observability 落地：BUG-005 修复验证 + BUG-006 新发现

**做了什么**：
- 实现 change `eval-harness-observability`（OpenSpec，分支 `codex/eval-harness-observability`）：
  - `AnalysisReport` 增加 `status` 字段；`EngineAnalyzeResponse` 增加 `sqlSource`。
  - `AgentController`：正常路径置 `status=SUCCESS`，等待审批路径置 `WAITING_APPROVAL` 且 `includeDebug` 时组装 `debug{resolvedIntent, sqlRetryCount, sqlSource}`。
  - Python `AnalyzeResponse`/`routes.py` 透传 `sqlSource`；eval runner `run_real_case` 读取 status/resolvedIntent/sqlSource。
- 修复评测链路可靠性：`LangGraphClient` 引擎超时 90s→180s。
- 重跑真实评测两次（中间修超时），最终 21/21 可用。

**Bug**：
- [BUG-005]（修复）现象：等待审批用例的报告丢失 status/resolvedIntent → c18 误判、c04/c08 L1 误算 0。原因：Spring 等待路径提前 return，未透传。修复：等待报告带 status + debug。验证：L1 84.62%→**100%**（13/13），c04/c10 正确显示 WAITING_APPROVAL。
- [超时]（修复）现象：评测偶发 500（c17 两连 ERROR），`agent_run.total_duration_ms=90000` + `LangGraph request failed`。原因：Spring HttpClient 90s 超时 < 真实 LLM p95 120s。修复：90s→180s。验证：最终 21/21 可用。
- [BUG-006]（新发现，未修）现象：真实评测 Source 列**全部 fallback**。根因：确定性合成器产出 `SELECT ... FROM md ...`，**用了别名却没声明 `FROM metric_daily md`** → MySQL `Table 'md' doesn't exist` → 执行/验证失败 → 降级 raw LLM 并覆盖 sql_source。即**语义合成路径在真实库从未成功过**，全靠 raw LLM 兜底（L1=100% 说明语义解析本身是好的）。修复方向（待开 change）：`synthesize()` 的 FROM 子句改为 `FROM {source} {alias}`，约 1 行 + 补真实执行测试。

**测试**：
- Python pytest 58/58（新增 `run_real_case` 观测解析测试）、ruff clean；Java `mvn test` 16/16（新增等待路径 + EngineAnalyzeResponse 映射测试）。
- 最终真实评测（15:08）：可用性 100%（21/21）、端到端 66.67%（14/21）、**L1 100%**、L2 61.54%、L3 93.59%、L4 除 dimensions（61.54%）外全部 100%、延迟 p50 40.5s / p95 91.5s。
- c18/c19 本轮因 LLM 生成的 SQL 未触发审批而诚实 FAIL（status=SUCCESS expected=WAITING_APPROVAL）——观测已如实，护栏漏报属独立问题。

**结果**：
- 评测体系现在能如实观测审批状态、语义结果、SQL 来源；基线数字可信（L1=100%）。
- Source 列暴露 BUG-006（合成器从未生效），是最有价值的副产品。

**待办/下一步**：
- 开新 change 修复 BUG-006（合成器 FROM 别名），修复后 Source 列应显示 semantic，且端到端成功率/延迟应显著改善（省去 raw LLM 生成）。
- 护栏误报/漏报调查（c04/c10 误报、c18/c19 漏报）。
- 语义层 dimensions 抽取优化（L4 dimensions=61.54%）。
- 分支 `codex/eval-harness-observability` 待 push + PR。

## [2026-08-13] BUG-003 修复（chartType 反序列化）+ 真实 LLM 首轮评测

**测试**：
